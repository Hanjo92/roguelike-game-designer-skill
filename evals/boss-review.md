# Evaluation: Boss Review

## Prompt

> 최종 보스가 원거리 빌드를 막기 위해 투사체에 완전 면역이고, 소환 빌드를 막기 위해 소환수를 즉시 죽이며, 전투 후반에는 회피 불가능한 전방위 공격을 사용하게 하려고 해. 어려운 보스로 괜찮은지 리뷰해줘.

## Mandatory Checks

- Flags unavoidable damage and mandatory build invalidation as critical
- Identifies the mastery the boss should test
- Provides alternate solution classes for ranged and summon builds
- Replaces immunity with readable resistance, objectives, positioning, conversion, or phase rules
- Defines telegraph, recognition/decision/execution window, and recovery
- Describes a teach/test/transform/climax phase arc
- Includes representative-build tests and phase-specific metrics

## Strong Response Signals

- Preserves anti-cheese intent without erasing build investment
- Uses arena topology and target priorities to create pressure
- Separates difficulty from unfairness

## Critical Failure

Approving the unavoidable attack or complete mandatory build invalidation.
