# Evaluation: Run Pacing

## Prompt

> 35분짜리 액션 로그라이트인데 첫 15분이 지루하고, 20분 이후에는 빌드가 완성돼서 모든 적을 자동으로 녹여. 보상은 90초마다 하나씩 나오고 보스는 10분, 25분, 35분에 등장해. 런 구조를 고쳐줘.

## Mandatory Checks

- Diagnoses opening agency and late decision-collapse separately
- Defines a run contract and stage arc
- Sets milestones for first choice, enabler, identity, specialization, and climax
- Changes beat/reward meaning, not only reward frequency
- Uses threat-role, spatial, objective, or resource transformations after build completion
- Preserves strong-build fantasy while restoring decisions
- Defines recovery and director boundaries
- Provides telemetry for milestone timing and practical irrecoverability/automatic victory

## Strong Response Signals

- Uses power/threat bands for weak, median, and strong builds
- Turns bosses into mastery checks tied to prior acts
- Proposes a graybox or fixed-seed validation plan

## Failure Signals

- Merely reduces all rewards or increases all enemy health
- Treats every run as requiring identical pacing interventions
